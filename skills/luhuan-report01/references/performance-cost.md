# 性能与模型成本复盘

用于比较案例、模型或执行流程；没有日志时只给带条件的估算，不补造执行数据。

## 耗时

- 区分首次部署、首次可预览、最终验收和交付；首个被日志观测到的可预览时间只是就绪时间的上界。
- 并行任务的时长不能直接相加。工具区间重叠时用区间并集；剩余时间可能含推理、生成、调度和平台延迟，不等于纯模型时间。
- 删除某个等待区间后的时间只是反事实算术，不是优化重跑实测。不同输入、模式、版本和测试范围不能当作受控 A/B。
- 每例保留数据/几何检查、短预览和既有状态保护；共享引擎、编辑或导出发生变更时再回归对应路径；全浏览器和导出矩阵放批次验收。

## Token 与计费

- 按唯一请求/响应 ID 去重，再按任务和实际子代理归属聚合。继承到子会话中的父事件不重复计数；优先对账每次任务的最终计数。
- `cached_input_tokens` 是输入的子集，reasoning 通常是输出的子集；按供应商实际 usage 定义核验，不能重复加进总量。每轮重复的历史会计入累计输入。
- 汇总主代理与相关协作者、失败重做、交接及审核；明确隐藏服务端重试、未记录请求和实际账单是否可观测。
- 推理 effort 与服务速度档是不同设置。不能仅凭名称把高推理模式按高速服务倍数计费。
- 模型规格、价格、缓存写入规则、长上下文阈值和时段折扣均需查当前官方来源，记录日期与币种。本文件不固定任何模型价表。
- 长上下文阈值按每个请求判定；缓存写入若是替代输入类别，不在相同输入上重复叠加。字段缺失时列条件基线与敏感性范围。
- API 等价美元不是订阅实付账单；税费、额度、服务档、渠道加价和工具费分别说明。

## 模型切换判断

相同数字 token 乘另一模型价格仅是价格敏感性。分词器、图像 token、推理长度、上下文、缓存、失败重做和质量可能改变。缓存不跨供应商转移，协作者可在自身请求中建立缓存。

以“每个通过同一标准的场景总成本”比较，同时记录首个可预览/最终合格耗时与人工修正。先固定输入、契约、工具和验收深度，再做重复 A/B；小样本报告中位数与范围，不宣称稳定生产 p95。没有实测时只提出分工和试验目标，不承诺固定降价或同等质量。
